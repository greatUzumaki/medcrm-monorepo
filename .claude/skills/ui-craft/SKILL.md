# UI MedCRM

Пользователи — администраторы ресепшена и врачи, которые работают в системе весь день, часто с пациентом напротив. Приоритет: **скорость, плотность, предсказуемость, отсутствие ошибок**. Это CRM, не лендинг (лендинг: скилл `landing-astro`) — без декоративных градиентов, гигантских hero, анимаций ради анимаций.

## Дизайн-язык
- Токены — только CSS-переменные из `packages/ui/src/styles/tokens.css` (Tailwind v4 `@theme`). Хардкод цвета/размера запрещён.
- Нейтральная база (slate), один акцент (teal/medical blue), семантические: `success`, `warning`, `danger`, `info`. Цвет никогда не единственный носитель смысла — плюс иконка/текст.
- Шрифт: Inter / Geist, `tabular-nums` для времени, сумм, дозировок.
- Плотность: базовый шаг 4px, строки таблиц 36–40px, compact-режим как опция.
- Тёмная тема поддерживается с первого дня (токены, не `dark:` везде).
- Иконки: lucide-react, 16px в плотных местах.

## Компоненты
Сначала `packages/ui` → затем shadcn (`pnpm dlx shadcn@latest add <c>` в `packages/ui`) → только потом своё. Мед-блоки живут в `packages/ui/src/medical/`: `PatientBadge`, `AllergyAlert`, `VitalsGrid`, `AiDraftBanner`, `SlotGrid`.

## Паттерны экранов
- **Список** (пациенты, записи): TanStack Table, серверная пагинация/сортировка/фильтры, фильтры в URL (`nuqs`), sticky header, выбор строк, массовые действия, виртуализация > 200 строк.
- **Карточка пациента**: шапка с ключевыми данными и **аллергиями/предупреждениями всегда на виду**, вкладки (Обзор, Визиты, ЭМК, Документы, Счета, Коммуникации).
- **Расписание**: сетка врачи × время, drag-to-reschedule с подтверждением, текущее время линией, конфликты подсвечены.
- **Командная палитра** `⌘K`: поиск пациента, быстрые действия. Горячие клавиши для частых действий.

## Формы
react-hook-form + `zodResolver(<схема из @medcrm/contracts>)`. Валидация на blur, ошибки под полем, фокус на первую ошибку. Маски: телефон `+7 (___) ___-__-__`, СНИЛС, полис. Автосохранение черновиков для длинных форм (осмотр). Опасные действия — диалог с явным текстом последствия.

## Состояния — каждое обязательно
loading (skeleton той же геометрии, не спиннер на весь экран) · empty (что сделать дальше + CTA) · error (что случилось + повторить) · forbidden · offline-баннер.

## ИИ в UI
- Любой ИИ-контент в `AiDraftBanner`: пометка «Черновик ИИ», кнопки Принять / Изменить / Отклонить.
- Стриминг текста из Go SSE через `useSseStream` (`apps/web/src/lib/`), с кнопкой «Остановить» (abort).
- Показывать источники (какие записи карты использованы) кликабельно.

## Локаль
next-intl, все строки в `messages/ru.json`. Даты `dd.MM.yyyy`, время 24ч, TZ клиники, `Intl.NumberFormat('ru-RU', { style: 'currency', currency: 'RUB' })`. Склонения через ICU plural.

## a11y (WCAG 2.2 AA)
Всё доступно с клавиатуры, видимый focus ring, контраст ≥ 4.5:1, `aria-live` для тостов и обновлений расписания, label у каждого поля, hit-area ≥ 24px.

## Производительность
RSC для данных первого экрана, `Suspense` по секциям, `next/dynamic` для тяжёлого (редактор, графики), никакого client-fetch waterfall. ПДн не попадают в URL, ключи query и `localStorage`.

## Проверка
Запустить `pnpm -F web dev`, открыть экран, пройти все состояния, проверить клавиатуру и тёмную тему. Для крупного экрана — агент `ui-reviewer`.
